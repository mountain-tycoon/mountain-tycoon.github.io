# Mountain Tycoon – das Spiel

Aktuelle Fassung mit 2D- und 3D-Modus (React 19, Vite, three.js).

```bash
npm install
npm run dev        # http://localhost:5180 – ohne Anmeldung
npm run build      # Produktions-Build nach dist/ (mit Anmeldung, siehe .env.production)
```

- Anmeldung und Anmeldeserver: `worker/README.md`
