# Menü-Icons

Lege hier PNGs ab (transparenter Hintergrund, quadratisch, ca. 128×128 px).
Sobald eine Datei existiert, ersetzt sie automatisch das Emoji im Menü —
fehlt sie, bleibt das Emoji stehen. Kein Code-Änderung nötig.
